git log показывает общую историю всех коммитов
git diff показывает конкретную разницу между двумя разными версиями кодов или коммита
git show показывает подробную информацию о конкретном коммите
git log - s находит коммиты, в которых добавлялся или удалялся конкретный фрагмент текста
git blame показывает автора и номер коммита для каждой строчки файла calc.py, позволяя увидеть кто и когда написал каждую строчку кода
git restore возвращает файл к состоянию последнего сохраненного коммита
git restore --source=HEAD~2 позволяет достать и вернуть версию файла из более раннего коммита
git revert создает новый коммит, который отменяет изменения предыдущего. Это безопасно для общей истории GitHub, так как не удаляет старые ккоммиты и не ломает историю у других разработчиков
Примером опасного может быть git resert --hard. Стирает коммиты из истории, что может запутать других участников проекта и сломать ветку
